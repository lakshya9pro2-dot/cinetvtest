NanoServer Stream Worker

Online Serverless Stream Resolver Active

API Endpoints

  • GET /api/movie/{tmdb_id} — Resolve movie stream URL (e.g. /api/movie/550)
  • GET /api/tv/{tmdb_id}/{season}/{episode} — Resolve TV episode stream URL (e.g. /api/tv/1399/1/6)
  • GET /api/tmdb/movie/{tmdb_id} — Fetch TMDB metadata
  • GET /api/health — Live connectivity & diagnostics check (/api/health)
  • GET /api/test — Test upstream connection

Query Parameter Alternatives

  • /?type=movie&id=550
  • /?type=tv&id=1399&season=1&episode=6
